# Mi primer portafolio

Portafolio estudiantil creado para practicar desarrollo web y control de versiones con Git.

## Archivos

- `index.html`: contiene la estructura y el contenido de la página.
- `style.css`: contiene los estilos visuales.

## Cómo abrir el portafolio

Abre el archivo `index.html` en un navegador web.
